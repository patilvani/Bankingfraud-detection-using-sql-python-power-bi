# Banking fraud-detection-using-SQL-python-power-bi

# Project Overview
The Banking Fraud Detection Dashboard is an end-to-end data analytics project designed to analyze banking transactions and identify fraudulent activities. The project uses Python to generate synthetic banking data, MySQL for data storage, and Power BI to create an interactive dashboard for fraud analysis and business insights.
---

# Objective
The objective of this project is to:
- Analyze banking transaction data.
- Identify fraudulent transactions.
- Monitor fraud trends over time.
- Compare fraud across transaction types, payment methods, and account types.
- Build an interactive Power BI dashboard for business decision-making.

# Dashboard Features
The dashboard includes:
- Total Customers
- Total Accounts
- Total Transactions
- Total Transaction Amount
- Fraud Transactions
- Fraud Rate (%)
- Fraud vs Non-Fraud Analysis
- Transaction Type Analysis
- Payment Method Analysis
- Monthly Transaction Trend
- Account Type Analysis
- Interactive Filters (Slicers)

---

# Project Workflow
1. Generated synthetic banking data using Python.
2. Stored the generated datasets in CSV format.
3. Imported the datasets into MySQL.
4. Connected MySQL data to Power BI.
5. Created relationships between tables.
6. Developed DAX measures for KPIs.
7. Built an interactive fraud detection dashboard.

---
# Key Insights
- Fraud transactions can be monitored using interactive KPIs.
- Transaction type analysis highlights categories with higher fraud.
- Payment method analysis helps identify risky payment channels.
- Monthly trends reveal changes in transaction activity over time.
- Account type comparison provides additional fraud insights.
